# Catgirl Tea Cafe — Game Jam Project

## Тема джема
«Легкость» (философская легкость, расслабление после работы).

## Визуальный стиль
Строго два цвета: **Черный и Белый**.

## Концепция
Бесконечный казуальный симулятор приготовления чая/кофе для кошкодевочки, которая пришла с работы.

## Файловая структура

```
catgirl project/
├── index.html          # Стартовый экран с кнопкой "Начать"
├── game.html           # Основной экран: catgirl + чат + кнопка "Сварить"
├── cook.html           # Экран приготовления: кофемашина
├── catgirl gif.gif     # Спрайт кошкодевочки (анимация)
├── cofemachine.png     # Спрайт кофемашины
└── doc/
    └── project.md      # Этот файл — документация
```

## Что уже сделано

### index.html
- Чёрный фон
- Кнопка «Начать» по центру
- При клике → `game.html`

### game.html
- Контейнер с отступами 1% от каждого края экрана
- Catgirl GIF на весь контейнер (фон, object-fit: cover)
- **Чат-окно** слева (top: 10%, left: 2%) с заголовком "Catgirl" и сообщениями
- **Правая кнопка "Сварить"** (top: 34%, right: 9%, width: 14%, height: 32%)
  - По умолчанию невидима
  - При наведении показывается текст "Сварить" белым цветом со свечением
  - При клике → `cook.html`
- Сообщения в чате показываются с задержкой через JS

### cook.html
- Контейнер 1% отступы
- Изображение `cofemachine.png` на весь контейнер

## Планируемая механика (core loop)

1. Кошкодевочка генерирует заказ — в чате появляется сообщение с нужными ингредиентами
2. Игрок кликает по кнопкам ингредиентов (ещё не реализовано)
3. Игрок нажимает «Сварить» → проверка
4. Если правильно → очки + новый заказ
5. Если ошибка → Game Over

## Ингредиенты
- Вода
- Кофе
- Заварка
- Сахар
- Молоко
- Сироп

## Рецепты (заготовлено в первой версии)
1. Чёрный чай: Вода + Заварка
2. Чёрный кофе: Вода + Кофе
3. Чай с сахаром: Вода + Заварка + Сахар
4. Кофе с молоком: Вода + Кофе + Молоко
5. Чай с молоком: Вода + Заварка + Молоко
6. Капучино: Вода + Кофе + Молоко + Сахар
7. Кофе с сиропом: Вода + Кофе + Сироп
8. Чай с сиропом: Вода + Заварка + Сироп
9. Латте: Вода + Кофе + Молоко + Сироп
